# magani1.github.io

Developer portfolio and web CV of Mathews Agani, served by GitHub Pages from `main` at
[mathewlewisagani.github.io/magani1.github.io](https://mathewlewisagani.github.io/magani1.github.io/).

Static HTML, CSS, and vanilla JavaScript. No build step. Every page works with JavaScript disabled.

| Page | What it holds |
| --- | --- |
| `index.html` | Home: about, experience, projects, research, education, skills, contact |
| `internet-quality.html`, `roommate-match.html`, `kinertia.html` | Case studies |
| `research.html` | CoNEXT 2026 poster paper: question, testbed, method, findings |
| `cv.html` | Print source for `assets/Mathews-Agani-CV.pdf` (not linked from the site) |

The hero background is an AI-generated interior render whose creator does not require credit; the wall sign was removed.
