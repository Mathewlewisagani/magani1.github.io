Roommate-Match

Stable roommate matching, checked against a brute-force oracle.

Solo project · Node.js, Express, React, PostgreSQL, Redis, Socket.io, Jest

Code ↗Differential test ↗

No live demo. Run the tests to reproduce.

Problem

Roommates are one pool, not two sides, so Gale–Shapley doesn’t apply. Some pools have no stable matching.

What I did

Built the app (auth, Postgres, Redis presence, Socket.io chat), implemented Irving’s algorithm, and wrote the tests.

Result

38 tests pass. Irving’s output matches a brute-force oracle on 10,500 seeded random cases.

Run it

Key decision

Check the algorithm with differential testing.

Why
Rotation elimination is easy to get wrong. A brute-force oracle checks every small case directly, and seeded inputs make failures replayable.
Trade-off
The oracle only scales to about 10 people. With no stable matching, the app falls back to a greedy pairing.

Evidence: stableRoommates.js, PR #1
